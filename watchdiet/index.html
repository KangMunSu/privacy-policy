English

WatchDiet helps you record meals, estimated calories, weight and goals. Meal and weight records, goals and saved photos stay in your device's local storage. This version has no account, cloud backup, advertising or in-app purchases.

Photo analysis

When you explicitly request analysis after seeing the notice, the selected photo is sent over HTTPS to our development analysis server and OpenAI to identify visible foods and estimate portions and calories. Estimates can be edited before saving. The server removes image metadata, including location, before sending the image to OpenAI. Neither our server nor its database keeps the photo, food names, meal diary or weight. OpenAI processes the image under its own applicable terms and retention practices; our API requests that the response not be stored for model training or later retrieval (store:false), but this does not guarantee zero provider retention.

Server metadata and retention

To issue anonymous installation credentials and enforce the per-installation limit of 100 analyses per UTC day, our server stores an installation UUID, a hashed credential, daily usage counts, request UUID and processing status, and the photo-analysis notice version and consent time. A daily HMAC of the network IP address limits credential issuance; the raw IP address is not saved in that database. Request status, usage and IP HMAC records are retained for about two UTC days; consent history for 90 days. Installation credentials expire after 30 days and are removed under the server retention process. No meal or photo content is used for advertising.

Your choices

You can use manual meal recording without sending a photo. You can edit and delete local meal and weight entries in the app. Clearing app storage or uninstalling removes local records and photos on that device; Android automatic backup is disabled. See data deletion instructions for server metadata and support requests. Contact kangmunsu.dev@gmail.com about this policy or your data. This policy may be updated when the app's data handling changes.

日本語

WatchDietでは食事、推定カロリー、体重、目標を記録できます。食事・体重の記録、目標、保存した写真は端末内に保存されます。この版にはアカウント、クラウドバックアップ、広告、アプリ内購入はありません。

写真の分析

説明を確認して分析を明示的に依頼すると、選択した写真はHTTPSで当社の開発用分析サーバーとOpenAIに送られ、食品、量、カロリーを推定します。結果は保存前に修正できます。サーバーはOpenAIへの送信前に位置情報などの画像メタデータを削除します。当社のサーバーやデータベースは写真、食品名、食事日記、体重を保存しません。OpenAIは適用される規約と保存方針に従って処理します。APIはstore:falseを指定しますが、提供元での保存が完全にないことは保証できません。

サーバー情報と保存期間

匿名のインストール認証とインストールごとのUTC日付で1日100回の上限のため、インストールUUID、認証情報のハッシュ、日別利用回数、リクエストUUIDと処理状態、分析案内の版と同意時刻を保存します。接続元IPは認証発行制限用の日別HMACに変換し、元のIPはDBに保存しません。リクエスト状態、利用回数、IP HMACは約2 UTC日、同意履歴は90日保存します。認証情報は30日後に失効し、保存手順に従って削除します。

選択と削除

写真を送信せず手入力で記録できます。アプリ内で食事・体重の記録を編集・削除できます。アプリのデータ消去またはアンインストールで、その端末の記録と写真が削除されます。Androidの自動バックアップは無効です。詳細はデータ削除案内をご覧ください。お問い合わせ: kangmunsu.dev@gmail.com。

Análisis de fotos

Metadatos y conservación

Estados, contadores y HMAC se conservan unos dos días UTC; el historial de consentimiento, 90 días. La credencial caduca a los 30 días y se elimina mediante la política de retención.
