개인정보 처리방침

본 방침은 RealmWalker(이하 “본 앱”)의 개인정보 처리 방식을 설명합니다.

현재 배포 버전 1.0(버전 코드 2)은 개인정보를 수집하거나 제3자와 공유하지 않습니다.

1. 수집 및 공유하는 정보

본 앱에는 계정 또는 로그인 기능이 없으며 이름, 이메일 주소, 전화번호, 위치, 연락처, 광고 식별자 등의 개인정보를 수집하지 않습니다.

본 앱은 광고, 이용 분석, 충돌 보고, 결제 또는 소셜 SDK를 사용하지 않으며, 개인정보나 게임 이용 데이터를 개발자 또는 제3자 서버로 전송하지 않습니다.

2. 기기에 저장되는 게임 데이터

게임 진행 상황, 영웅 및 편성 상태, 설정과 같은 게임 데이터는 이용자의 기기에만 저장됩니다. 이 데이터는 기기 밖으로 전송되지 않으며 이용자를 식별하기 위한 목적으로 사용되지 않습니다.

Android 설정에서 본 앱의 저장 데이터를 삭제하거나 본 앱을 제거하면 기기에 저장된 게임 데이터가 삭제됩니다.

3. 네트워크 및 외부 서비스

현재 버전은 개발자 서버나 제3자 온라인 서비스에 접속하지 않습니다. 앱에는 향후 버전형 콘텐츠를 내려받을 수 있는 기술적 기능이 포함되어 있으나 현재 배포 설정에서는 서버 주소가 지정되지 않아 동작하지 않습니다.

향후 광고, 분석, 계정, 클라우드 저장, 원격 콘텐츠 또는 그 밖의 데이터 처리를 도입하는 경우 해당 기능이 포함된 버전을 배포하기 전에 본 방침과 Google Play 데이터 보안 신고를 갱신합니다.

4. 아동의 개인정보

본 앱은 만 13세 미만의 아동을 대상으로 하지 않으며, 아동의 개인정보를 고의로 수집하지 않습니다.

5. 개인정보 처리방침 페이지

본 개인정보 처리방침 페이지는 GitHub Pages에서 제공됩니다. 이용자가 이 페이지를 웹 브라우저로 열 때 발생하는 접속 정보의 처리는 GitHub의 개인정보 보호정책 및 이용 중인 브라우저의 정책을 따릅니다. 이는 본 앱이 수행하는 데이터 수집이 아닙니다.

6. 방침의 변경

본 방침이 변경되는 경우 이 페이지에 변경된 내용과 시행일을 게시합니다.

7. 문의

Privacy Policy

This policy explains how RealmWalker (the “App”) handles information.

The current release, version 1.0 (version code 2), does not collect personal data or share it with third parties.

1. Information Collected or Shared

The App has no account or login feature and does not collect personal information such as names, email addresses, phone numbers, location, contacts, or advertising identifiers.

The App does not use advertising, analytics, crash-reporting, payment, or social SDKs. It does not transmit personal information or gameplay data to the developer or third-party servers.

2. Game Data Stored on the Device

Game progress, hero and formation state, settings, and similar game data are stored only on the user's device. This data is not transmitted off the device and is not used to identify the user.

Game data stored on the device is removed when the user clears the App's storage in Android settings or uninstalls the App.

3. Network and External Services

The current release does not connect to developer servers or third-party online services. The App contains technical support for downloading versioned content in a future release, but no server address is configured in the current distribution, so that feature does not operate.

If a future release introduces advertising, analytics, accounts, cloud saves, remote content, or any other data processing, this policy and the Google Play Data safety declaration will be updated before that release is distributed.

4. Children's Privacy

The App is not directed to children under 13 and does not knowingly collect personal information from children.

5. This Privacy Policy Page

This privacy policy page is hosted on GitHub Pages. When a user opens this page in a web browser, access information may be processed under GitHub's privacy statement and the policies of the browser being used. This is separate from the App and is not data collection performed by the App.

6. Changes to This Policy

Changes to this policy will be posted on this page together with the new effective date.

7. Contact

For questions about this Privacy Policy, contact kangmunsu.dev@gmail.com.
