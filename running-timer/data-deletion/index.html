1. What you can delete

ScopeWhat is deletedHow
One local activityActivity details and all associated GPS route points; grass and statistics are recalculatedDelete the activity from its detail screen in the App
All local dataActivities, raw routes, recovery state, grass/statistics, pending summaries, and local consent stateAndroid Settings → Apps → Running Timer → Storage → Clear storage, or uninstall the App
Leave leaderboardRunning Timer leaderboard consent and all Running Timer daily totals on the Haru Studio server; public rank contribution is removedSettings → Leaderboard → Leave leaderboard, when the optional account feature is enabled
Delete app accountRunning Timer account linkage, Firebase authentication user, consent, daily totals, and associated public rank contributionSettings → Privacy & data → Delete account, when the optional account feature is enabled, or use the email request below

Deleting a Running Timer app account does not delete your Google Account or data belonging to other Google services. Local GPS data is never uploaded to our server and therefore cannot be erased remotely; clear App storage or uninstall on each device that contains it. Android cloud backup is disabled, so App data is not restored through Android Auto Backup.

2. Current in-app availability

Google sign-in and account creation are not currently exposed in the App UI. Before a release enables leaderboard sign-in, it must also provide the in-app “Leave leaderboard” and “Delete account” paths described above. The external email request on this page is available now.

3. Request deletion from the web

  1. Email kangmunsu.dev@gmail.com with the subject [Running Timer] Account and Data Deletion Request.
  2. State whether you want to leave the leaderboard or delete the Running Timer app account and associated server data.
  3. Send from the Google email used to sign in when possible, or include that email address so we can locate and verify the account. You may include the anonymous leaderboard code if available.
  4. Do not send your Google password, Firebase token, screenshots containing tokens, or GPS route coordinates. We will never ask for them.

We will normally acknowledge the request within 7 business days and complete verified deletion within 30 days. If applicable law permits or requires a different period, we will explain the reason and expected date. A support email may be retained for up to 30 days after completion to resolve the request, then deleted unless longer retention is legally required.

4. What remains after deletion

  • Our active systems retain no Running Timer leaderboard totals, consent record, or public-code association for the deleted account.
  • Firebase Authentication states that logged IP addresses are retained for a few weeks and that, after we initiate user deletion, other authentication information is removed from live and backup systems within 180 days.
  • Information processed independently by Google Maps or other Google services follows Google's controls and policies. Deleting the Running Timer account does not delete a Google Account.
  • We may retain only information that applicable law strictly requires, or limited evidence needed for security, fraud prevention, dispute resolution, or compliance. If this applies to your request, we will tell you the category and reason.

Running Timer 앱 계정을 삭제해도 Google 계정이나 다른 Google 서비스의 데이터는 삭제되지 않습니다. 로컬 GPS 데이터는 당사 서버로 업로드되지 않으므로 원격으로 삭제할 수 없습니다. 데이터가 있는 각 기기에서 앱 저장공간을 지우거나 앱을 제거하십시오. Android 클라우드 백업을 꺼 두었으므로 Android Auto Backup으로 앱 데이터가 복원되지 않습니다.

2. 현재 앱 내 기능 상태

현재 앱 UI에는 Google 로그인과 계정 생성이 노출되어 있지 않습니다. 리더보드 로그인을 활성화하는 출시본은 그 전에 위의 앱 내 “리더보드 참여 종료”와 “계정 삭제” 경로도 함께 제공해야 합니다. 이 페이지의 외부 이메일 요청은 지금 이용할 수 있습니다.

3. 웹에서 삭제 요청하기

  1. kangmunsu.dev@gmail.com으로 이메일을 보내고 제목을 [Running Timer] 계정 및 데이터 삭제 요청으로 작성합니다.
  2. 리더보드 참여 종료 또는 Running Timer 앱 계정과 연결된 서버 데이터 삭제 중 원하는 범위를 적습니다.
  3. 가능하면 로그인에 사용한 Google 이메일에서 보내거나 해당 주소를 본문에 적어 계정을 찾고 확인할 수 있게 해 주십시오. 알고 있다면 익명 리더보드 코드를 함께 적어도 됩니다.
  4. Google 비밀번호, Firebase 토큰, 토큰이 보이는 화면, GPS 경로 좌표는 보내지 마십시오. 당사도 이를 요구하지 않습니다.

일반적으로 영업일 기준 7일 안에 요청을 접수하고, 본인 확인이 끝난 삭제 요청은 30일 안에 완료합니다. 적용 법률이 다른 기간을 허용하거나 요구하면 이유와 예상 일자를 안내합니다. 요청 해결을 위해 지원 이메일을 완료 후 최대 30일간 보관한 뒤 삭제할 수 있으며, 법률이 더 긴 보관을 요구하는 경우는 제외합니다.

4. 삭제 후 남을 수 있는 정보

  • 당사의 활성 시스템에는 삭제한 계정의 Running Timer 리더보드 합계, 동의 기록 또는 공개 코드 연결이 남지 않습니다.
  • Firebase Authentication은 기록한 IP 주소를 수 주간 보관하고, 당사가 사용자 삭제를 시작한 뒤 다른 인증 정보는 운영·백업 시스템에서 최대 180일 안에 제거한다고 밝힙니다.
  • Google Maps나 다른 Google 서비스가 독립적으로 처리한 정보에는 Google의 관리 기능과 정책이 적용됩니다. Running Timer 계정 삭제는 Google 계정을 삭제하지 않습니다.
  • 적용 법률이 엄격하게 요구하거나 보안, 사기 방지, 분쟁 해결 또는 규정 준수에 필요한 최소한의 증빙만 보관할 수 있습니다. 해당되는 경우 범주와 이유를 안내합니다.

Running Timerのアプリアカウントを削除しても、Googleアカウントや他のGoogleサービスのデータは削除されません。ローカルGPSデータは当社サーバーにアップロードされないため、遠隔では削除できません。データがある各端末で本アプリのストレージを消去するか、本アプリをアンインストールしてください。Androidクラウドバックアップは無効であり、Android Auto Backupからアプリデータは復元されません。

2. 現在のアプリ内機能

現在、Googleログインとアカウント作成は本アプリのUIに公開されていません。 リーダーボードログインを有効にするリリースでは、その前に上記のアプリ内「リーダーボードから退出」と「アカウントを削除」の経路も提供する必要があります。本ページの外部メールリクエストは現在利用できます。

3. ウェブから削除を依頼する方法

  1. kangmunsu.dev@gmail.comへ、件名を[Running Timer] アカウントとデータの削除依頼としてメールを送信します。
  2. リーダーボードから退出、またはRunning Timerのアプリアカウントと関連サーバーデータを削除のどちらを希望するか記載してください。
  3. 可能であればログインに使用したGoogleメールから送信するか、そのメールアドレスを本文に記載して、アカウントの特定と確認ができるようにしてください。分かる場合は匿名リーダーボードコードも記載できます。
  4. Googleパスワード、Firebaseトークン、トークンが写った画面、GPSルート座標を送らないでください。当社もこれらを求めません。

通常、7営業日以内に受領を連絡し、本人確認済みの削除依頼は30日以内に完了します。適用法令が別の期間を認める、または求める場合は、理由と予定日をご案内します。サポートメールは依頼解決のため、完了後最大30日保持してから削除する場合があります。ただし、法令がより長い保持を求める場合を除きます。

4. 削除後に残る可能性がある情報

  • 当社の稼働中システムには、削除したアカウントのRunning Timerリーダーボード合計、同意記録、公開コードとの関連付けは残りません。
  • Firebase Authenticationは、記録したIPアドレスを数週間保持し、当社がユーザー削除を開始した後、その他の認証情報をライブおよびバックアップシステムから180日以内に削除すると説明しています。
  • Google Mapsまたは他のGoogleサービスが独立して処理した情報には、Googleの管理機能とポリシーが適用されます。Running Timerアカウントの削除はGoogleアカウントを削除しません。
  • 適用法令が厳密に求める情報、またはセキュリティ、不正防止、紛争解決、法令順守に必要な最小限の証拠のみ保持する場合があります。該当する場合は、情報の区分と理由をお知らせします。
